# SedLog-Lithology-Symbology-Upgrade
A pre-assembled SedLog 3.x modification containing a large number of new, ready to use lithology symbols covering sedimentary, metamorphic and igneous rocks.

The provided symbols have been taken from the Federal Geographic Data Comittee publication on digital cartographic standards for geological map simbolization (FGDC-STD-013-2006), specifically series 600 and 700.

The lithology .svgz files themselves were acquired from https://github.com/davenquinn/geologic-patterns, afterwhich they were recategorized and sorted into SedLog folders for symbology storage, additionally, a .DAT file was created to facilitate the addition of the new symbols inside the software itself.

To install this modification, simply extract the data and symbology folders into the main SedLog directory, if you have any saved preferences or existing new symbology, make sure to merge the folders instead of replacing them to avoid data loss.
